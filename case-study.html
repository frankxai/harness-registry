Reproduce it

Public, MIT, stdlib-only: oh-my-starlight (package) and starlight-ai-harness (template). Probe with python fleet/harness_matrix.py --probe; run the matrix with --all; render tables with --report.

Caveats

3 single-shot / 7 agentic tasks - directional, not final rankings. One machine, one day; latency varies with provider load. Free tiers are bursty (a daily cap was hit and recorded). Policies are labeled per row and never averaged together.

Method: deterministic graders only (real code, real asserts). If a number cannot be measured it is reported as unrecorded. Maintained by frankxai.
